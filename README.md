# 🪐 DesignVerse — Student Design & Innovation Fest

A high-conversion, responsive single-page landing page built for the student festival **DesignVerse**.

## 🛠️ Technologies Used
- **HTML5:** Semantic structuring.
- **Tailwind CSS:** Modern, responsive component styling.
- **Vanilla JavaScript:** Form handling and success states.

## 🚀 Setup & Execution
1. Clone or download this repository.
2. Open the `index.html` file directly in any web browser to view the page.
